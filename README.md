# BMI Calculator 🧮

A simple BMI calculator built as part of **Angela Yu's 100 Days of Code: The Complete Python Pro Bootcamp**.

## What I Practiced

- Getting user input with `input()`
- Converting strings to numbers with `float()`
- Storing values in variables
- Performing mathematical calculations
- Displaying results with `print()`

## How It Works

The program asks for the user's height and weight, then calculates their BMI using:

**BMI = weight / height²**
